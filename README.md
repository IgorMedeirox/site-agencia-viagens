## 🌍 What's this project about?

**Jornada Viagens** is a fictional travel agency website created as a front-end training project. It sells dreams — and also plane tickets, hotel + flight combos, travel insurance, and transfers. The idea is simple: make visitors feel the urge to pack their bags before they even finish scrolling.

The project is currently composed of two main pages:

- **[index.html](index.html)** — the homepage, with weekly offers, categories, popular destinations, payment options, and testimonials.
- **[pacotes-de-viagens.html](pacotes-de-viagens.html)** — a dedicated landing page for a Japan travel package (because who doesn't want to visit Japan?).

## 🛠️ Tech stack

This project is intentionally simple. No frameworks, no build step, no JavaScript wizardry — just:

- **HTML5** for semantic, accessible markup
- **CSS3** for styling, layout, and responsiveness
- **Modular CSS** files imported into a main `style.css`

```
jornada-viagens/css/
├── style.css         # Imports everything
├── global.css        # Variables, resets, utilities
├── header.css        # Navigation and logo
├── hero.css          # Big hero sections
├── offers.css        # Weekly offer cards
├── categories.css    # Category navigation cards
├── destinations.css  # Destination details
├── payments.css      # Payment section layout
├── testimonials.css  # Customer testimonials
└── footer.css        # Footer styling
```

## 🚀 How to run it

No `npm install`. No `npm start`. No terminal drama.

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/site-agencia-viagens.git
   ```

2. Open `index.html` in your favorite browser.

3. Done. Go explore.

> 💡 **Pro tip:** if you want a slightly fancier local server, use the VS Code **Live Server** extension and watch the magic happen with auto-reload.
